# 🛡️ FraudSight AI

An Explainable AI-powered fraud detection dashboard built using XGBoost, SHAP, and Streamlit for analyzing financial transactions.

## Features

- Real-time fraud prediction
- CSV upload for batch analysis
- Fraud risk levels
- SHAP explainability
- Fraud trends dashboard
- Downloadable prediction report
- Model performance comparison

## Tech Stack

- Python
- Streamlit
- XGBoost
- SHAP
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Dataset

Kaggle Credit Card Fraud Detection Dataset

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
